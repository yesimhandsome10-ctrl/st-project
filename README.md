## 방법
선택한 방법은 군집이다. 원본 데이터에 직접적인 선고 형량 변수가 없으므로 억지로 인과식을 세우는 회귀 대신, 실제 관측된 재범 양상만으로 110개 세부 범죄를 비슷한 그룹으로 먼저 묶은 뒤 각 군집에 어떤 처벌 수위의 범죄들이 모여 있는지 비교해 엄벌의 재범 억제 효과를 검증하고자 군집 분석을 선택했다.

분석 과정(실제로 한 일, 단계마다 무엇을·어떻게·왜):데이터 수집: 국가통계포털 범죄분석통계에서 2024년 전과자 재범기간 및 종류 엑셀 파일을 내려받았다.

변수 선택: 범죄 발생 규모 차이에 따른 왜곡을 막기 위해 비율 변수 3가지 동종재범률, 단기 1년 이내 재범률, 장기 3년 초과 재범률을 군집화 입력 변수로 선택했다.

전처리: 3줄로 병합된 헤더를 정리하고, 중복 집계되는 전체 합계·중분류 소계 행과 결측 행을 제외해 최하위 세부 범죄 110개(총 629,069명)를 추출한 뒤, 세 비율 변수의 단위 차이를 맞추기 위해 표준화를 적용했다.

분할: 군집 분석은 정답 라벨이 없는 비지도학습이므로 학습·평가 분할 대신 110개 전체 범죄 유형의 구조적 패턴을 탐색하는 전체 데이터 군집화를 수행했다.

기준선: 110개 범죄를 전혀 나누지 않고 하나의 집단(전체 평균)으로 묶었을 때의 군집 내 오차제곱합을 기준선으로 설정했다.

후보 모델 비교: 군집 개수를 2개부터 5개까지 바꾸며 K-평균 모델을 실행해 오차제곱합 감소율과 군집 분리도를 비교했다. 

선택: K=2는 단순히 높음/낮음 으로만 이분화되어 흉악범죄와 일반 과실범죄가 섞이는 한계가 있어, 범죄 유형의 특성을 가장 명확하게 해석할 수 있는 K=3`을 최종 모델로 선택했다.

평가: 기준선 대비 오차제곱합감소율(62.6% 감소)과 실루엣 계수(0.333)로 군집 형성의 타당성을 평가했다.

해석: 도출된 3개 군집의 평균 재범률과 각 군집에 속한 대표 범죄들의 법정 처벌 수위 중형·징역형 vs 벌금형·집행유예 를 대조해 해석했다.

한계 점검: 실제 선고 형량 데이터 부재 및 재범하지 않은 출소자 미포함 한계를 점검했다.
